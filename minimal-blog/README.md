# The Daily Draft — Blog Sample

개인 블로그 컨셉 CMS 템플릿 샘플 (정적 HTML).

## 사이트명

**The Daily Draft** — 헤더, 푸터, 타이틀, `posts.json` 전역 사용.

## 페이지

| 파일 | Wix |
|------|-----|
| `index.html` | Home |
| `blog.html` | Blog (Dynamic List) |
| `post.html?slug=` | Blog post (Dynamic Item) |
| `about.html` | About |

python3 -m http.server 3456
